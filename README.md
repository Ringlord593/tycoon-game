# Project Details

We will be using Godot 4.7.2 - .**NET**. You will need to download the installer from https://godotengine.org/download/windows/. Make sure to select the .Net version.

GitHub Desktop is recommended. 

Each developer owns one feature/system at a time. All work must be linked to a GitHub Issue and performed in a dedicated branch. See Below.

## Developer Workflow 

1. Select Projects from the navigation bar at the top and click the Tycoon Game Project.

2. Select a feature or system from the To Do column to view details. 

3. Assign yourself to the issue using the dropdown in the assignees column before beginning work. 

4. Change the issue status from To Do to In Progress using the status column. 

5. Select the name of the feature in the first column to see the details, then scroll down until you see Development on the right hand side. 

6. Select Create a branch. Enter the name: feature/\<issue-number\>-feature-name. See current branches for examples.

7. Commit changes regularly using clear commit messages. 

8. Push the branch to GitHub when the feature is functional.

10. Create a pull request or notify Nathan that the feature is ready. 

11. After approval and merge, move the issue to Done.
